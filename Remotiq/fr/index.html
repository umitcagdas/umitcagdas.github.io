Installation

L'app de bureau doit être ouverte sur l'ordinateur et l'app mobile sur le téléphone.

1

Installez l'app de bureau

Installez Remotiq Desktop Agent sur Windows ou macOS et laissez-le ouvert.

2

Ouvrez l'app mobile

Ouvrez Remotiq sur le téléphone. Les deux appareils doivent utiliser le même Wi-Fi.

3

Associez par QR

Scannez le QR affiché sur l'ordinateur. Les connexions suivantes pourront être automatiques.

Confidentialité

Les commandes ne transitent pas par un relais internet Remotiq. Les rapports Firebase facultatifs peuvent être désactivés dans les réglages. La caméra sert uniquement à l'association QR et le réseau local à trouver l'ordinateur.
