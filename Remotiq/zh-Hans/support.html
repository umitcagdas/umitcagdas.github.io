首次设置

  1. 在电脑上安装 Remotiq Desktop。
  2. 将手机和电脑连接同一 Wi-Fi。
  3. 在手机上点击连接到电脑。
  4. 扫描桌面应用中的二维码。
  5. 配对后将手机用作遥控器。

找不到电脑

  • 确认两台设备使用同一 Wi-Fi。
  • 暂时关闭 VPN。
  • 在 Windows 防火墙中允许专用网络访问。
  • 在 iPhone 上启用局域网权限。
  • 发现失败时使用二维码或手动配对。

macOS 权限

在 Mac 上控制鼠标和键盘需要辅助功能权限。使用 Remotiq Desktop 中的权限按钮，必要时重启应用。

Windows 提示

首次运行时 Windows 可能询问防火墙权限。请允许专用/局域网访问。部分受保护应用可能因系统限制拒绝远程输入。

安全与隐私

命令保留在局域网中并需要受信任设备。Remotiq 没有账号或命令中继；可关闭 Firebase 可选报告。
