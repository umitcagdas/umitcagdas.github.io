设置

电脑上需打开桌面应用，手机上需打开移动应用。

1

安装桌面应用

在 Windows 或 macOS 上安装并运行 Remotiq Desktop Agent。

2

打开移动应用

两台设备连接同一 Wi-Fi 后打开 Remotiq。

3

扫描二维码配对

扫描电脑显示的二维码，之后可自动重连。

隐私

命令不会经过 Remotiq 互联网中继。可在设置中关闭可选的 Firebase 使用和诊断报告。摄像头仅用于二维码配对，局域网权限仅用于发现并连接电脑。
