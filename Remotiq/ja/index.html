PC/Macリモコンをポケットに

パソコンの操作を 手のひらに。

スマートフォンからマウス、キーボード、メディア、ブラウザ、アプリ操作を同じWi-Fi経由で利用できます。

デスクトップアプリをダウンロード設定方法

アカウントもクラウド中継も不要。スマートフォンはローカルネットワーク上でパソコンに直接接続します。

ソファからパソコンを操作

パソコンにインストールし、スマートフォンをペアリングすればすぐに操作できます。

⌁

マウスとキーボード

ポインター移動、クリック、スクロール、スマートフォンのキーボード入力に対応します。

▶

メディアとブラウザ

再生、音量、ブラウザのタブ、基本的な移動操作をコントロールします。

✓

ローカルネットワークの信頼

コマンドはローカルネットワーク内に留まり、ペアリング済みの信頼できる端末が必要です。

設定

パソコンでデスクトップアプリ、スマートフォンでモバイルアプリを開いてください。

1

デスクトップアプリをインストール

WindowsまたはmacOSにRemotiq Desktop Agentをインストールして起動します。

2

モバイルアプリを開く

両方の端末を同じWi-Fiに接続してRemotiqを開きます。

3

QRコードでペアリング

パソコンに表示されたQRコードを読み取ります。次回以降は自動接続できます。

ダウンロード

先にRemotiq Desktopをインストールし、スマートフォンでQRコードを読み取ってください。

macOS

Remotiq Desktop for Mac

Apple Silicon Macをスマートフォンからマウス、キーボード、メディアリモコンとして操作します。

Mac版をダウンロード
Windows

Remotiq Desktop for Windows

同じローカルネットワークのスマートフォンとWindows PCをペアリングします。

Windows版をダウンロード
iPhone

Remotiq for iOS

App StoreからiPhoneにRemotiqをインストールし、パソコンとペアリングします。

App Storeからダウンロード
Android

Remotiq for Android

Google Play版の公開準備が整い次第、Androidリンクを掲載します。

デスクトップ版は公開リリースファイルとして配布されます。モバイル版リンクは公開時に更新します。

プライバシー

コマンドはRemotiqのインターネット中継を通りません。任意のFirebase利用・診断レポートは設定で無効にできます。カメラはQRペアリング、ローカルネットワークはパソコンの検出と接続だけに使用します。

プライバシーポリシーを読む

ヘルプ
