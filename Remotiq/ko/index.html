컴퓨터 제어를 손안에서.

같은 Wi-Fi에서 마우스, 키보드, 미디어, 브라우저와 앱을 휴대폰으로 제어하세요.

데스크톱 앱 다운로드설정 방법

계정과 클라우드 중계가 없습니다. 휴대폰이 로컬 네트워크에서 컴퓨터에 직접 연결됩니다.

Remotiq실행 중

빠른 연결

휴대폰 연결

  1. 1휴대폰에서 Remotiq을 엽니다.
  2. 2컴퓨터에 연결을 누릅니다.
  3. 3QR 코드를 스캔합니다.

연결 준비 완료

QR 코드 스캔

소파에서 컴퓨터 제어

컴퓨터 앱을 설치하고 휴대폰을 페어링하면 바로 사용할 수 있습니다.

⌁

마우스와 키보드

포인터 이동, 클릭, 스크롤과 휴대폰 키보드 입력을 지원합니다.

▶

미디어와 브라우저

재생, 음량, 브라우저 탭과 기본 탐색을 제어합니다.

✓

로컬 네트워크 신뢰

명령은 로컬 네트워크에 머물며 페어링된 신뢰 기기가 필요합니다.

설정

컴퓨터에서 데스크톱 앱을, 휴대폰에서 모바일 앱을 열어 두세요.

1

데스크톱 앱 설치

Windows 또는 macOS에 Remotiq Desktop Agent를 설치하고 실행합니다.

2

모바일 앱 열기

두 기기를 같은 Wi-Fi에 연결하고 Remotiq을 엽니다.

3

QR 코드 페어링

컴퓨터의 QR 코드를 스캔하면 이후 자동 연결할 수 있습니다.

다운로드

Remotiq Desktop을 먼저 설치한 뒤 휴대폰으로 QR 코드를 스캔하세요.

macOS

Remotiq Desktop for Mac

휴대폰을 Apple Silicon Mac의 마우스, 키보드와 미디어 리모컨으로 사용하세요.
