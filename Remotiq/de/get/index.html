Für Windows herunterladenMSI-Option
  1. Installieren: Öffnen Sie die heruntergeladene Datei auf Ihrem Computer.
  2. Starten: Lassen Sie Remotiq Desktop geöffnet.
  3. Verbinden: Scannen Sie den QR-Code mit Remotiq auf Ihrem Smartphone.

Smartphone und Computer müssen im selben WLAN sein. Remotiq verbindet direkt im lokalen Netzwerk, nicht über die Cloud.
