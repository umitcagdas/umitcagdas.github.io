Kebijakan Privasi

Kontrol lokal tetap milik Anda; pengukuran adalah pilihan Anda.

Remotiq bekerja di jaringan lokal tanpa akun atau relay internet untuk perintah. Laporan penggunaan, crash, dan performa Firebase dapat dimatikan.

Terakhir diperbarui: 1 Agustus 2026

Ringkasan

  • Perintah tetap antara ponsel dan komputer yang dipasangkan di jaringan lokal.
  • Remotiq tidak memiliki akun atau relay internet untuk perintah.
  • Firebase digunakan untuk laporan penggunaan samaran, negara, sesi, crash, dan performa.
  • Dapat dimatikan di Pengaturan > Privasi & diagnostik.
  • Versi beriklan dapat menggunakan Google Mobile Ads.
  • Detail komputer dan kunci aman disimpan di perangkat.
  • Kamera hanya digunakan untuk pemasangan QR.

Data yang Diproses

Remotiq mobile 1.0.3 build 20 dan yang lebih baru memakai Firebase Analytics, Crashlytics, dan Performance Monitoring. Layanan ini dapat memproses ID instans samaran, pembukaan pertama, sesi dan durasi, layar, metode dan hasil sambungan, versi, bahasa, perangkat dan OS, negara/wilayah perkiraan dari Google, crash, serta performa. Remotiq tidak menetapkan nama, email, telepon, atau ID akun ke Firebase.

Untuk pemasangan dan sambungan ulang, nama komputer, host/port, platform, sambungan terakhir, ID perangkat, token aman, dan preferensi hanya disimpan di perangkat.

Alamat dan IP/port komputer, kode, ID dan token, teks, URL, nama aplikasi, dokumen, dan tangkapan layar tidak ditambahkan ke peristiwa atau bidang crash Firebase.

Izin

Kamera
Hanya untuk memindai QR pemasangan Remotiq.
Jaringan Lokal / Bonjour
Untuk menemukan dan terhubung ke Remotiq Desktop di Wi-Fi yang sama.
Internet / Jaringan
Untuk sambungan lokal, pemeriksaan pembaruan, Firebase opsional, dan Google Mobile Ads pada versi beriklan.

Berbagi dan Iklan

Perintah dan rahasia pemasangan tidak dikirim ke server Remotiq. Google Firebase dapat memproses data terbatas tersebut untuk analitik, diagnostik, dan performa.

Google User Messaging Platform memeriksa pilihan privasi sebelum iklan. Di iOS, pelacakan personal memerlukan App Tracking Transparency; penolakan tidak memblokir fitur inti.

Diagnostik dan Dukungan

Anda dapat menyalin ringkasan diagnostik berisi status, versi, platform, nama komputer, dan kode kesalahan. Token dikecualikan.

Saat pengukuran aktif, Crashlytics dapat memproses jejak crash, kesalahan yang disunting, perangkat, dan OS tanpa identitas pengguna atau rahasia sambungan.

Menghapus Data

Melupakan komputer menghapus detail dan token aman dari ponsel. Menonaktifkan Firebase mereset data Analytics di perangkat dan menghentikan pengumpulan berikutnya. Menghapus aplikasi menghapus data lokal.

Privasi Anak

Remotiq tidak ditujukan untuk anak-anak dan tidak meminta data akun yang langsung mengidentifikasi.
