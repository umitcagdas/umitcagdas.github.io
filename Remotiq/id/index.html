Penyiapan

Aplikasi desktop dan aplikasi seluler harus terbuka.

1

Instal aplikasi desktop

Instal Remotiq Desktop Agent di Windows atau macOS dan biarkan berjalan.

2

Buka aplikasi seluler

Hubungkan kedua perangkat ke Wi-Fi yang sama lalu buka Remotiq.

3

Pasangkan dengan QR

Pindai kode QR di komputer. Sambungan berikutnya dapat berlangsung otomatis.
