Dukungan Remotiq

Bantuan penyiapan dan sambungan

Remotiq bekerja antara ponsel dan komputer Anda pada jaringan lokal yang sama.

Tautan unduhan

Unduh untuk Mac / WindowsSemua unduhanKebijakan Privasi

Aplikasi iPhone tersedia di App Store. Tautan Android ditambahkan setelah rilis.

Penyiapan pertama

  1. Instal Remotiq Desktop di komputer.
  2. Hubungkan kedua perangkat ke Wi-Fi yang sama.
  3. Buka Remotiq dan ketuk Hubungkan ke Komputer.
  4. Pindai QR aplikasi desktop.
  5. Gunakan ponsel sebagai remote.

Komputer tidak ditemukan

  • Pastikan kedua perangkat memakai Wi-Fi yang sama.
  • Matikan VPN sementara.
  • Izinkan Remotiq di jaringan privat Windows Firewall.
  • Aktifkan izin Jaringan Lokal di iPhone.
  • Gunakan QR atau pemasangan manual jika penemuan gagal.

Izin macOS

Kontrol mouse dan keyboard di Mac memerlukan izin Aksesibilitas. Gunakan tombol izin di Remotiq Desktop dan mulai ulang bila perlu.

Catatan Windows

Windows mungkin meminta izin firewall. Izinkan jaringan privat/lokal. Beberapa aplikasi terlindungi dapat menolak input jarak jauh.

Keamanan dan privasi

Perintah tetap di jaringan lokal dan memerlukan perangkat tepercaya. Tidak ada akun atau relay perintah; pelaporan Firebase opsional dapat dimatikan.
